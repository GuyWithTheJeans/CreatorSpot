CREATORSPOT: START HERE
=======================

Sorry this takes a few steps! Right now this is the easiest way to install
CreatorSpot: Chrome and Brave only allow one-click installs from the Chrome
Web Store. It takes about 2 minutes and you only do it once.

1. Make sure you UNZIPPED this first.
   Right-click the ZIP file > "Extract All..." > "Browse..." > Desktop > "Extract".
   (If you only double-clicked the ZIP to look inside, it will not work.)

2. Open the CreatorSpot folder on your Desktop and double-click
   "Install CreatorSpot".

   A window pops up and shows you every click, with pictures.
   If Windows asks "Do you want to run this file?", click "Run"
   (or "More info" > "Run anyway").

Keep the CreatorSpot folder on your Desktop. Deleting it removes the extension.

Updates install themselves automatically. Just leave Developer mode ON and
keep this folder where it is. (If an update ever gets stuck, click the
CreatorSpot icon and press "Update now".)
